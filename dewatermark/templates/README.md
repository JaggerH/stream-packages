# 水印模板

`app.py` 启动时把这个目录下所有 `*.png` 读成灰度模板，在四个角做多尺度匹配。

| 文件 | 来源 | 量法 |
|---|---|---|
| `ai-shengcheng-preview.png` | 豆包网页版「图像生成」的**预览图**左上角「AI 生成」标，从 2048² 样张裁 `(39,39)-(299,150)` | 对左上 300² 区域取中位色当背景，与背景差 >40 的像素的包围框 |
| `doubao-ai-shengcheng-download.png` | 豆包网页版**下载**按钮给的那份图右下角的「豆包AI生成」文字（无底框），从 2848×1600 样张裁 `(w-284,h-92)-(w-18,h-28)` | 放大看边界手量的；本机验证：那张样张匹配 1.00、落在右下 |

加模板：从真实样张裁（别手画），裁紧到标的圆角框边缘，灰度 PNG。模板要能在**没有水印**的图上匹配不到
（分数 < `DEWATERMARK_MATCH_MIN`，默认 0.6）——加完拿一张干净图跑一次 `/remove` 看响应头不是 `matched`。
